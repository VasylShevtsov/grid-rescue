GRID RESCUE — START HERE

Grid Rescue now includes the Java model and a playable Swing desktop interface.
The repository root is the directory containing README.md, pom.xml, and src/.

BUILD AND PLAY
With Java 11 or newer and Maven available, run from the repository root:
  mvn clean verify
  java -jar target/grid-rescue-1.0-SNAPSHOT.jar

Alternative launch after compiling and testing:
  mvn test
  java -cp target/classes edu.whitman.ui.GridRescueApplication

The game window requires a graphical desktop. Swing is included with Java; no
external runtime libraries are required. The first Maven build may download
build plugins and test dependencies.

Select a unit in the squad, on the map, or with keys 1–4; click a legal tile
to move. Arrow keys move map focus; Enter or Space activates the tile. Use
Pick up survivor while standing on a survivor; use Deliver cargo while carrying
survivors at the shelter. The P and D shortcuts perform those same actions.
Rescue A, B, C, and D and bring the CommandUnit to a shelter within 80 actions.
How to play explains movement, terrain, capacities, upgrades, and the outcome
rules. It opens in the same window; H opens it and Escape returns to play. Restarting
a mission with progress asks for confirmation. The outcome summary offers Play again.
