Interface and unit symbols: Lucide Icons and Contributors.
Source: https://github.com/lucide-icons/lucide/tree/main/icons
License: ISC; some icons derived from Feather carry its MIT license.
Official SVG files are preserved next to local 96x96 PNG renderings.
The source shape paths are unchanged. PNG strokes are forest green;
GameArt recolors these using the source alpha channel for each context.
Unit symbols use binoculars, cross, truck and radio.

Outfit-Regular.ttf and Outfit-SemiBold.ttf are fixed-weight instances
(weight 400 and 600) of the original Outfit variable font. They were
instantiated with fontTools 4.67.0 so Java renders their intended weights
consistently. Only these static instances and the license are shipped;
the unused variable font is omitted. The original can be reproduced from
the official Google Fonts source URL and the checksum below.
